## How I work

- **Keyless by design** — public / free API tiers, clean credential handling
- **Real execution only** — an agent step is done when a tool actually ran; scripts ship with their verified workflow steps
- **Automation-first** — agents run on schedules (cron), deliver to Telegram &amp; Discord, escalate to me when signals break rules
- German + English content pipelines
